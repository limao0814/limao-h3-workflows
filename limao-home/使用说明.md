# 🐱 狸猫AI · H3 工坊 使用说明

> 本文件夹是工作流备份副本。**日常使用请直接打开 ComfyUI 网页**（仙宫云控制台 → 自定义服务 8188 端口入口）。

## 🚀 三个入口

| 入口 | 位置 | 说明 |
|---|---|---|
| **ComfyUI 网页（主入口）** | 仙宫云控制台 → 自定义服务 `8188` | 打开即见**起始欢迎页**；左侧「工作流」面板 → **狸猫视频 / 狸猫图片** 文件夹 → 点开即可用 |
| **本文件夹** | Jupyter `/root/狸猫H3工坊/` | 七个工作流 JSON 备份副本（ComfyUI 网页里也能直接拖入使用） |
| **狸猫平台（狸猫AI）** | limaocg.cn 用户端 | 无需自己开实例，在线提交生成任务 |

## 📁 七大主线工作流

### 狸猫视频
- **狸猫H3工作流** —— 多参考图 + 多参考音频生视频（1536×960，24fps，最长 15s，超长自动分段拼接）

### 狸猫图片
- **文生图** —— 提示词生成高清大图（最高 16MP，无风格 LoRA 基础版）
- **图生图** —— 16 图参考改图 / 合成（基础版）
- **文生图（自然真实风格）** —— 狸猫自训真实风 LoRA，触发词 `limaoreal`
- **图生图（自然真实风格）** —— 参考图改图 + 真实风 LoRA
- **文生图（MJstyle）** —— 狸猫自训 MJ 风格 LoRA（493 张 MJ 码图精训），提示词已预置触发词 `mjstyle`，高饱和时尚大片质感
- **图生图（MJstyle）** —— 参考图改图保留构图 + MJ 风格 LoRA

## 💡 使用提示
1. ComfyUI 网页左侧 **工作流面板** → 狸猫视频 / 狸猫图片 → 点开模板
2. 修改提示词节点文字（自然真实风格请保留触发词 `limaoreal`；MJstyle 风格请保留开头 `mjstyle,`，任何提示词加上它即出 MJ 质感）
3. 参考图 / 音频槽已预填示例文件（`参考图.jpg`、`音频.wav`），可换成自己的
4. 点击右上角 **运行（Queue）** 开始生成，产物在 `ComfyUI/output`

## ❓ 为什么 Jupyter 里之前看不到狸猫文件夹？
工作流浏览器里的「狸猫视频 / 狸猫图片」文件夹是 **ComfyUI 网页内部的工作流库**（存放在 `/root/ComfyUI/user/default/workflows/`），不在 /root 根目录下。本文件夹是便于查找的备份副本。ComfyUI 的**起始欢迎页**同样在 ComfyUI 网页里：首次打开（或画布空白时）自动加载。
